تعليمات تشغيل مشروع المقرأة (Docker)
----------------------------------

هذا المجلد يحتوي على نسخة جاهزة للتشغيل من التطبيق باستخدام Docker.

المتطلبات:
- تثبيت برنامج Docker Desktop على الجهاز.

خطوات التشغيل:

الطريقة الأولى :
1. افتح التيرمينال (Terminal) في هذا المجلد.
2. قم باستيراد الصورة أولاً بالأمر التالي:
   docker load -i al_maqraa_app.tar
3. قم بتشغيل الحاوية باستخدام الأمر:
   docker-compose up -d

4. افتح المتصفح وادخل على الرابط التالي:
   http://localhost:8080


الطريقة الثانية :
1. استيراد الصورة:
   docker load -i al_maqraa_app.tar
2. تشغيل الصورة:
   docker run -d -p 8080:80 --name al_maqraa_container al_maqraa_app:latest
